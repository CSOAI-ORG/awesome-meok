## 🎯 Quick Start

Install the entire MEOK governance fleet with one command:

```bash
npx meok-setup --pack governance
```

Or install individual MCPs:

```bash
# EU AI Act compliance
pip install git+https://github.com/CSOAI-ORG/eu-ai-act-compliance-mcp

# Agent orchestration
pip install git+https://github.com/CSOAI-ORG/agent-orchestrator-mcp

# NIS2 compliance
pip install git+https://github.com/CSOAI-ORG/nis2-compliance-mcp
```
